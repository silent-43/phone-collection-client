# 📱 Phone Collection - Frontend

A modern and responsive Phone Collection web application built with React.js.

## 🌐 Live Website

https://phone-collection-client.web.app

## 🚀 Features

- 📱 Display all phones
- ➕ Add new phone
- 🔍 View phone details
- ✏️ Update phone information
- 🗑️ Delete phone
- 🖼️ Display phone images
- 📱 Responsive design
- 🎨 Modern UI with Tailwind CSS & DaisyUI
- 👤 Developer profile shortcut
- 🚀 Firebase Hosting deployment

## 🛠️ Technologies Used

- React.js
- JavaScript
- React Router
- Tailwind CSS
- DaisyUI
- Vite
- Firebase Hosting
